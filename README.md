# PowerShell Preworkout (PSPreworkout) Extension Pack

[![Version](https://img.shields.io/visual-studio-marketplace/v/SamErde.pspreworkout-powershell-extensions-pack)](https://marketplace.visualstudio.com/items?itemName=SamErde.pspreworkout-powershell-extensions-pack)
[![Installs](https://img.shields.io/visual-studio-marketplace/i/SamErde.pspreworkout-powershell-extensions-pack)](https://marketplace.visualstudio.com/items?itemName=SamErde.pspreworkout-powershell-extensions-pack)

PSPreworkout is a pack of Visual Studio Code extensions to optimize your environment while working on PowerShell projects and documentation.

![PSPreworkout Logo (Designed with Microsoft Designer)](https://raw.githubusercontent.com/SamErde/PSPreworkout-VSCode-Extension-Pack/main/images/PSPreworkout-Extension-Pack-Banner.png)

This pack of extensions contains many essential tools for working on PowerShell modules and scripts. My workflow involves managing all code on GitHub and creating documentation in Markdown. As a result, I consider GitHub and Markdown-related extensions to be key components of this pack. However, if you prefer, you can still selectively install only the extensions that you want to use.

**Note:** To support the use of cross-platform environments, this extension pack does not contain any OS-specific extensions (e.g.: WSL).

**Note:** All credit and much gratitude goes out to the awesome community members that have freely made these extensions available. 💛 I have not created any of them myself.
